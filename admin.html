A PLACE FOR EVERYTHING

Store setup

Your storefront stays on GitHub Pages. Your API handles the rest.

From draft to connected store.

  1. Prepare the collection

    Add products, descriptions and confirmed prices here. Export a catalogue backup before switching browsers.

  2. Set up the store API

    Deploy the included Cloudflare Worker and D1 database. Configure an admin email and a password hash in server secrets.

  3. Connect the storefront

    Add the API URL to site-config.js and set the storefront URL and allowed origins on the server.

  4. Test Stripe, then enable checkout

    Start with test credentials, register the webhook and test a payment. Switch to live keys after the owner confirms all business details.

Full developer instructions: backend/README.md in the repository.
